# 朋友圈点赞截图生成器

一个完全在本地浏览器中运行的截图合成工具。它保留原始朋友圈截图的尺寸、状态栏、正文、主题和底部评论栏，只在指定位置加入点赞头像区域。

## 使用

1. 双击 `start.bat`。
2. 浏览器打开后，选择原始朋友圈截图，或直接使用默认的 `原图.jpg`。
3. 设置点赞数量；需要时上传自定义头像或拖动预览中的点赞栏。
4. 点击“下载图片”。

点赞数量支持 0–99，头像来源有三种：

- **内置头像**：来自两张样例截图，共 39 个；超过 39 个时会循环使用。
- **网络头像包**：从 Random User Generator 的公开测试数据接口下载并缓存的 99 张真人风格占位头像，不会重复；生成图片时不需要联网。
- **上传头像**：使用自己选择的图片；数量超过上传图片数时会循环使用。

所有图片处理都在浏览器本地完成，不会上传到网络。

## 文件说明

- `index.html`：程序入口。
- `app.js`：自动识别主题、定位、头像排版与图片导出。
- `styles.css`：界面样式。
- `assets/avatars/`：从用户提供的样例图中提取的内置头像。
- `assets/web-avatars/`：已缓存的网络头像包；`sources.json` 记录每张图的原始地址与校验值。
- `tools/extract_avatars.py`：重新提取内置头像的脚本。
- `tools/download_web_avatars.py`：重新下载、去重并缓存网络头像包的脚本。
