# 朋友圈点赞截图生成器

一个完全在本地浏览器中运行的截图合成工具。它保留原始朋友圈截图的尺寸、状态栏、正文、主题和底部评论栏；如果原图已经带点赞，会先抹掉原有点赞栏，再按当前数量重新绘制。

## 使用

1. 双击 `start.bat`（Windows）或在项目目录运行 `python3 -m http.server 8767 --bind 0.0.0.0`。
2. 浏览器打开 `http://127.0.0.1:8767/`，选择或拖入原始朋友圈截图，或使用默认的 `原图.jpg`。
3. 设置点赞数量；需要时上传自定义头像或拖动预览中的点赞栏。
4. 点击“下载图片”。

点赞数量支持 0–200，头像来源有三种：

- **内置头像**：来自两张样例截图，共 39 个；超过 39 个时会循环使用。
- **网络头像包**：预先从百度图片按多种国内头像关键词缓存约 1000 张（卡通/动漫/简约/萌宠等），200 以内不重复；「随机换一批」会按风格分桶后均匀穿插。生成图片时不需要联网。
- **上传头像**：使用自己选择的图片；数量超过上传图片数时会循环使用。

所有图片处理都在浏览器本地完成，不会上传到网络。

## 文件说明

- `index.html`：程序入口。
- `app.js`：自动识别主题、定位、头像排版与图片导出。
- `styles.css`：界面样式。
- `assets/avatars/`：从用户提供的样例图中提取的内置头像。
- `assets/web-avatars/`：已缓存的网络头像包；`sources.json` 记录每张图的来源、风格与校验值。
- `tools/extract_avatars.py`：重新提取内置头像的脚本。
- `tools/download_web_avatars.py`：重新下载、去重并缓存网络头像包的脚本。

重新生成网络头像包（需要 Pillow，建议用项目内 `.venv`）：

```bash
python3 -m venv .venv
.venv/bin/pip install Pillow
.venv/bin/python tools/download_web_avatars.py
```
